# ミッシング立ち位置練習

絶・妖星乱舞 P2「ミッシング」の立ち位置を、ロールとデバフごとにクリックで答えて覚えるための練習ページです。

- 公開ページ: https://poultice.github.io/missing_sim/
- 動きで確認するアニメ版: `anim.html`（①〜⑧と過去・未来の誘導、実時間再生、塔の実際の方位）。公開ページ: https://poultice.github.io/missing_sim/anim.html
- 基準: 固定の勉強用スライド（りーん準拠（KTDN）一部改）
- 1ファイルのHTMLで、ビルドや外部ライブラリは不要です。

座標は `index.html` の `POS`（ボス中心・フィールド半径1）にまとめてあります。立ち位置を直すときはここを変更してください。

`anim.html` の座標も `POS` に集約してあり、練習ページの `POS` と同じ値です。立ち位置を直すときは両方を変更してください。時刻の元データ（FFLogsの敵詠唱）の出典は `anim.html` の `REAL` のコメントにあります。
